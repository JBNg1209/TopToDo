# Roadmap

## Near term

- Expand focused regression coverage for persistence compatibility and Today/Task Pool limits.
- Add UI smoke automation once stable accessibility identifiers and isolated app data are available.
- Validate release metadata so README links, versions, DMG names, and checksums stay in sync.
- Surface persistence save/load failures without silently losing user confidence.

## Product polish

- Refine empty and limit states only where they reduce confusion.
- Review keyboard workflows and accessibility for adding, editing, moving, and deleting tasks.
- Audit trilingual copy before each release.

## Deferred

- Cloud sync, accounts, recurring tasks, due dates, tags, priorities, project folders, menu-bar mode, and iOS/iPadOS/web clients are out of scope until there is a clear product need.
