# TopToDo documentation

This directory is the versioned source of truth for product, engineering, and release knowledge. Keep it concise, current, and linked from `AGENTS.md` so people and coding agents can discover the relevant context without relying on local files or chat history.

| Document | Use it for | Update it when |
| --- | --- | --- |
| [product.md](product.md) | Product behavior and non-negotiable rules | A user-visible behavior or scope boundary changes |
| [architecture.md](architecture.md) | Module map and dependency rules | A module or responsibility changes |
| [development.md](development.md) | Setup, validation, and tooling | Build or test workflow changes |
| [release.md](release.md) | Packaging and publishing checklist | Release inputs or signing flow changes |
| [roadmap.md](roadmap.md) | Planned and deferred work | Priorities or scope decisions change |
| [changelog.md](changelog.md) | Released user-facing changes | A release is prepared |
